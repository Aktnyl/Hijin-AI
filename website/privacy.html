Data Protection

Zero-Data Privacy Guarantee

Your financial documents, supplier invoices, journal entries, and reconciliation outputs never leave your workstation.

1. Your Workspace Remains Local

User documents, imported invoices, database tables, and workspace state remain strictly on your local machine. Hijin does not operate cloud storage buckets, document processing servers, or intermediary ingestion pipelines.

2. AI Inference on Your Machine

All neural inference is executed locally using quantized models loaded into your workstation's system memory (RAM) or graphics card memory (VRAM). Document text is never transmitted to external cloud AI APIs.

3. Transparent Network Communication Disclosures

In accordance with our strict factual transparency policy, we do not make false claims like "nothing ever connects to the internet." Network access occurs solely for the following controlled functions:

  • Cryptographic License Check: The desktop client connects once every 7 days to verify active subscription status and receives an Ed25519-signed token. No document names or accounting figures are transmitted.
  • Model Hub Downloads: When you initiate a model installation or update, the application connects to the official distribution repository to download verified model packages over HTTPS.
  • Software Updates: The client checks for signed application release packages when update checking is enabled.

4. Zero Website Surveillance

This public website does not employ Google Analytics, Meta Pixel, tracking beacons, advertising cookies, or behavioral recording scripts.

5. Data Erasure & Uninstallation

All local workspace state and databases reside in %LOCALAPPDATA%\Hijin. Deleting this directory permanently removes all application records from your system.
