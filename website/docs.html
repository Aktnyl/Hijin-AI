Chapter 1

Getting Started & System Architecture

Hijin is a private, local-first desktop AI workbench engineered specifically for corporate accounting, audit, and finance professionals. Unlike cloud AI tools that ingest your sensitive ledgers onto third-party servers, Hijin runs completely locally on your Windows workstation.

Two-Tier Binary Architecture

Hijin separates the lightweight user application from the high-throughput inference engine:

  • Desktop Application Shell (Tauri 2): Native Windows desktop UI compiled in Rust and WebView2. Consumes under 180 MB of RAM while rendering fluid 60 FPS interfaces.
  • Rust Daemon Sidecar (hijin_daemon.exe): Embedded background process that runs on localhost (127.0.0.1:49210). Handles local SQLite ledger storage, GGUF model memory allocation, and token streaming.
  • Dual-Core Neural Pack: Local quantized weights loaded directly into CPU RAM or GPU VRAM without requiring an active internet connection.

Zero Cloud Upload Architecture

When you drag and drop invoice PDFs, bank statements, or ERP ledgers into Hijin, they are parsed and stored in your local application directory (%LOCALAPPDATA%\Hijin\data). No financial records ever cross your network perimeter.

Chapter 3

Windows Installation & SmartScreen Guide

Hijin is packaged as a standard Windows executable installer (Hijin_Setup_1.0.0.exe, 6.58 MB) created with NSIS.

Installation Directory

By default, Hijin installs to the user profile without requiring elevated Administrator privileges:

Default Installation Path 
%LOCALAPPDATA%\Programs\Hijin\

Navigating Windows SmartScreen

Because Hijin is an independent software release, Windows SmartScreen may display an informational modal stating "Windows protected your PC":

  1. Click the More info link in the SmartScreen dialog.
  2. Confirm the publisher is Hijin Tech or the app is Hijin_Setup_1.0.0.exe.
  3. Click Run anyway to execute the setup wizard.
Chapter 4

Dual-Core Model Hub & Weights Management

Hijin features a two-tiered neural architecture designed for specialization and synthesis:

Core 1: Specialist

Hijin Financial Specialist (6.2 GB)

Domain-adapted model trained on financial ledgers, tax codes, and invoice structures. Outputs structured JSON matching payloads with zero floating-point arithmetic.

Core 2: Synthesizer

Gemma 3 Conversation Core (6.1 GB)

General-domain executive intelligence core for drafting audit variance memos, explaining tax discrepancies, and synthesizing PowerPoint briefings for board meetings.

Resumable Model Hub Streaming

The in-app Model Hub streams weights with chunked checksum validation directly from the official Hugging Face CDN. If your network connection drops, the download resumes from the exact byte where it paused.

Chapter 5

Deterministic Decimal Reconciliation Engine

Standard large language models fail at corporate accounting because they hallucinate calculations or use standard IEEE-754 floating-point mathematics, which introduces rounding errors like 0.1 + 0.2 = 0.30000000000000004.

Fixed 28-Digit Decimal Precision

Hijin delegates all arithmetic to a deterministic Rust mathematical engine using fixed 28-digit precision:

  • Two-Way Matching: Matches Purchase Order line items against Vendor Invoices with exact line-level reconciliation.
  • Three-Way Matching: Matches Purchase Order, Receiving Inspection Ticket (Goods Receipt Note), and Vendor Invoice with tolerance thresholds configured by the user.
  • Zero Rounding Drift: Tested across 100,000 synthetic transaction pairs with 0.00000% decimal drift.
Chapter 6

Forensic Grounding & Audit PDF Export

Every finding generated by Hijin includes verifiable evidence coordinates. If the model flags a $450 variance between an invoice and a purchase order, it displays the bounding-box highlight on the original PDF scan.

With one click, you can generate an audit-ready Forensic Verification PDF or Executive Briefing PPTX containing full citations, document hashes, and mathematical proofs ready for partner review or external auditor submission.

Chapter 7

Licensing, Cryptographic Verification & Offline Grace

Hijin uses Ed25519 asymmetric cryptography to sign and verify commercial license tokens.

7-Day Offline Entitlement

Unlike aggressive cloud DRM that crashes when you lose internet connectivity, Hijin checks in only once every 7 days. If you are traveling or working in an air-gapped facility, the desktop app functions with 100% capability for up to 7 full days offline.

Chapter 8

Troubleshooting & Common Error Codes

Reference table for resolving setup, daemon connection, or model download errors.

Error Code Diagnostic Meaning Recommended Resolution
ERR_DAEMON_PORT_BOUND Port 49210 is occupied by another process. Restart Hijin or run Stop-Process -Name hijin_daemon in PowerShell.
ERR_MODEL_DISK_FULL Insufficient disk space to stream GGUF model weights. Ensure at least 15 GB of free disk space is available on the target drive.
ERR_TOKEN_EXPIRED 7-day offline grace period has concluded. Connect to the internet briefly to refresh your Ed25519 license token.
ERR_VRAM_FALLBACK GPU VRAM was exhausted during large batch processing. Hijin automatically transitions to CPU multi-threaded RAM fallback.
