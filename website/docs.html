1. Getting Started with Hijin

Hijin is an autonomous desktop artificial intelligence workbench engineered specifically for financial audit, reconciliation, and compliance workflows. Unlike browser-based cloud AI tools that transmit confidential accounting data across public networks, Hijin runs directly on your local Windows operating system.

Core Operational Principles

  • Local Workstation Processing: All prompt evaluation, token parsing, and document inspection occur locally.
  • Deterministic Validation Layer: The AI model does not calculate arithmetic in isolation; every math operation and invoice reconciliation is verified through deterministic Python calculation routines.
  • Grounded Provenance: Whenever Hijin identifies a number or discrepancy, it returns bounding box coordinates pointing directly to the source invoice or bank statement.

2. Windows Installation

The official Windows release is distributed as a single executable setup package: Hijin_Setup_1.0.0.exe.

Installation Workflow

  1. Download the validated installer from the Download page.
  2. Double-click the installer executable. You may install for the current user or machine-wide.
  3. The installer deploys the native Tauri 2 desktop application, the packaged background daemon sidecar (hijin_daemon.exe), and default configuration templates.
  4. Upon completion, check "Launch Hijin" and click Finish.

User Data vs Application Files

Installation binaries reside in %LOCALAPPDATA%\Programs\Hijin (per-user) or C:\Program Files\Hijin (system). Your customer documents, conversations, settings, and generated artifacts reside safely in %LOCALAPPDATA%\Hijin. Uninstalling or upgrading Hijin will never delete your documents or conversation history.

3. Account & Trial Activation (C8 Flow)

On first launch, Hijin presents an intuitive onboarding wizard:

  • Screen 1 (Welcome): Introduces Hijin and initiates onboarding.
  • Screen 2 (Account): Allows you to create a new Hijin Tech commercial account or sign into an existing one.
  • Screen 3 (Trial / License): Automatically issues or synchronizes a 14-day server-authoritative Free Trial. If you possess a commercial license, entering your activation key binds your device.
  • Screen 4 (Runtime Initialization): Probes the local execution daemon, checks model provider availability, and mounts the local workspace.
  • Screen 5 (Ready): Enters the primary financial workbench.

4. Cryptographic Licensing Engine (P26 Ed25519)

Hijin uses an asymmetric Ed25519 cryptographic licensing authority. Every commercial license is a digitally signed envelope containing:

  • Customer and account identifiers.
  • Licensed capability allowlist (e.g., financial_reconciliation, artifact_generation).
  • Validity timestamps and monotonic clock rollback protection.
  • Device binding hardware hashes (supporting up to 2 workstations per account).
  • Digital signature verifiable with Hijin Tech's public verification key.

5. Offline Entitlements & Grace Periods

We recognize financial professionals often work in air-gapped environments, on airplanes, or during client site audits without internet access.

  • 30-Day Offline Cache: Once activated, Hijin caches your verified entitlement envelope locally. You can use full features offline for up to 30 days without network contact.
  • 5-Day Renewal Grace Period: If a scheduled renewal payment is delayed, Hijin grants a 5-day grace period to ensure critical ongoing audits are never interrupted.
  • Permanent Data Preservation: Even if a subscription lapses completely, all local documents, conversations, and exported artifacts remain 100% accessible and exportable.

6. Forensic Audit & Briefing Artifacts

Hijin produces verified executive and forensic artifacts:

  • Executive Briefings (.pptx): Native PowerPoint presentation decks with financial summary slides, discrepancy callouts, and recommendations.
  • Forensic Audit Briefs (.pdf): Multi-page audit reports generated with ReportLab, featuring complete mathematical verification ledgers and document coordinate citations.
  • System Reveal & Viewer: Click "Open in PowerPoint", "Open in PDF Reader", or "Show in Explorer" directly from the Hijin desktop interface.

8. In-App AI Model Hub & Local Weight Management

Hijin features an integrated visual Model Hub—similar to Jan or LM Studio—allowing users to manage local models without touching a command-line terminal.

Hijin Financial Specialist (4B GGUF)

Fine-tuned on financial reconciliation, tax validation, and audited PDF extraction. Streamed directly into %APPDATA%\Hijin\models via chunked resumable HTTP range transfers.

Connected Ollama Hub (127.0.0.1:11434)

If you already run Ollama locally, Hijin automatically binds to your existing Gemma weights, eliminating redundant multi-gigabyte downloads.

7. Diagnostics & Support

If you experience runtime or connectivity issues:

  • Click the License Badge in the top header to inspect license validity, key ID, offline days remaining, and device status.
  • Use Settings → Diagnostics to verify daemon health on 127.0.0.1:8765 and inspect model provider status.
  • Submit diagnostic telemetry bundles to support@hijintech.com for priority review.
