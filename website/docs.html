Architecture

Getting Started

Hijin is an autonomous local-first desktop application engineered for corporate accounting, audit reconciliation, and financial document analysis. Unlike cloud SaaS products that transmit ledger contents to third-party APIs, Hijin operates entirely inside your local operating system environment.

Local Isolation Standard

When you import invoices, Purchase Orders, or bank statements into Hijin, they are parsed and indexed locally in %LOCALAPPDATA%\Hijin\data. Documents are never uploaded to Hijin servers or external cloud AI services.

Setup

Installation Guide

Hijin is packaged as an NSIS Windows installer (Hijin_Setup_1.0.0.exe, 6.58 MB) targeting Windows 10 and 11 (64-bit x86_64).

Installation Procedure:

  1. Download the validated installer from the Downloads page.
  2. Double-click the setup executable. The software installs to %LOCALAPPDATA%\Programs\Hijin\ without requiring administrative privileges.
  3. If Windows SmartScreen displays a warning modal, select More info then Run anyway.
Onboarding

First Launch & Activation

Upon launching Hijin for the first time, the application presents the First-Launch Activation Wizard:

  • 14-Day Free Evaluation: Click "Start 14-Day Free Trial" to generate an authentic cryptographic evaluation token tied to your workstation. No credit card is required.
  • Commercial License: If you have an active commercial subscription, enter your license key to activate full offline entitlements.
Neural Distribution

Model Hub & Neural Cores

Hijin separates application binaries from neural weight packages. Models are distributed in GGUF (Q4_K_M) format and managed through the in-app Model Hub:

  • Hijin Financial Specialist (~6.0 GB): Domain-adapted model fine-tuned for two-way/three-way matching and discrepancy verification.
  • Gemma 3 4B IT (~6.0 GB): General conversational reasoning core licensed under Google Gemma Terms of Use.
Input Data

Document Processing

Hijin processes native PDF files (containing embedded text layers and vector tables), structured CSV records, and JSON accounting streams. All document parsing executes via native background routines with zero network transmission.

Verification

Financial Reconciliation & Decimal Engine

Standard large language models fail at mathematical accounting because they use floating-point mathematics prone to rounding drift. Hijin couples neural parsing with a compiled deterministic math engine:

  • Calculations are verified using fixed 28-digit precision.
  • Two-way matching compares Purchase Orders and Vendor Invoices.
  • Three-way matching reconciles Purchase Orders, Receiving Goods Receipts, and Invoices against user-defined tolerance thresholds.
Auditability

Evidence & Artifact Generation

Every finding extracted by Hijin preserves precise spatial coordinates (page number and bounding box). When review is complete, the application generates a self-contained Forensic Audit PDF containing verifiable mathematical proofs.

Network Policy

Offline Mode & Licensing

Hijin checks license status online once every 7 days. If your machine is disconnected for travel or field auditing, it operates with full functionality for up to 7 consecutive days offline.

Troubleshooting & Common Issues

Error Diagnostic Underlying Cause Resolution Procedure

ERR_INSUFFICIENT_DISK Target drive has under 15 GB free space for model weights. Free disk space on your local user drive.
ERR_GRACE_EXPIRED Workstation has exceeded 7 consecutive days offline. Connect to the internet briefly to refresh cryptographic license token.
