# Security Policy

## Supported Versions
Only the latest release of Hijin Workstation receives security and cryptographic updates.

| Version | Supported |
| :--- | :--- |
| 1.0.x | :white_check_mark: |
| < 1.0.0 | :x: |

## Reporting a Vulnerability
We take cryptographic integrity and local data isolation seriously.

If you discover a security vulnerability, cryptographic weakness, or unintended network communication in Hijin:
* **Email:** security@hijintech.com (or open a confidential GitHub Security Advisory)
* **Response Time:** We acknowledge reports within 24 hours and issue remediation within 5 business days.
* **Please do NOT disclose vulnerabilities publicly until a patch has been released.**
