# Feature Request Guidelines

Have an idea for a new accounting connector, document parser, or workflow integration?

Submit your request in [GitHub Discussions: Feature Requests](https://github.com/Aktnyl/Hijin-AI/discussions/categories/feature-requests) or open an issue using the Feature Request template.

## Helpful Details to Include
* Name of accounting platform (e.g., QuickBooks Desktop, Xero, NetSuite, SAP).
* Exact file export formats (.CSV, .XLSX, standard PDF audit formats).
* Specific reconciliation rule or math calculation required.
