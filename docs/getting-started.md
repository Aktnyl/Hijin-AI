# Getting Started with Hijin Workstation

Welcome to Hijin, the private, local-first AI cognitive workstation for financial analysis, reconciliation, and audit reporting.

## 1. Quick Start in 3 Steps
1. **Download:** Get the installer from [Download Page](https://aktnyl.github.io/Hijin-AI/download.html) or [GitHub Releases](https://github.com/Aktnyl/Hijin-AI/releases).
2. **Install:** Run `Hijin_Setup_1.0.0.exe` and allow the installer to provision the local runtime and Dual-Core Neural Pack.
3. **Activate:** Launch Hijin. Click "Start Free Trial" in the Model Hub or enter your active license key (`HJN-...`).

## 2. Key Perspectives in the App
* **Reconciliation Workspace:** Import bank statements, ledger exports, and invoice batches for deterministic math validation.
* **Audit Artifacts Viewer:** Review line-by-line mismatch analysis, variance explanations, and exportable audit briefs.
* **Cognitive Chat:** Query your local documents using natural language powered by Gemma 3.
* **AI Model Hub:** Monitor local GGUF model statuses, check RAM allocation, and verify license state.
