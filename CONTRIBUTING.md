# Contributing to Hijin Public Repository

We welcome community contributions to our public documentation, website guides, accounting format templates, and benchmark reports!

## Ways to Contribute
1. **Improve Documentation:** Fix typos, add clarification, or expand hardware benchmark tables.
2. **Submit Accounting Templates:** Provide anonymized `.CSV` sample headers for ERP platforms (QuickBooks, Xero, NetSuite) to help expand reconciliation parser coverage.
3. **Share Benchmarks:** Submit hardware execution reports in GitHub Discussions.

## Code of Conduct
Please review and adhere to our [Code of Conduct](CODE_OF_CONDUCT.md) in all community interactions.
